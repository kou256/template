# 出力テンプレート

提案は次の固定フォーマットで提示します。承認を得るまでコミットや分割の実行は行いません。

## 単一コミットの場合

```
## ステージ済み差分
<git diff --staged --stat の要約。ファイル数と主な変更点を簡潔に>

## 判定
単一のまとまりとしてコミットできます。

## コミットメッセージ案
<種類>: <絵文字> 説明

（必要なら本文）

この内容でコミットしてよいですか？修正があれば指示してください。
```

## 分割コミットの場合

```
## ステージ済み差分
<git diff --staged --stat の要約>

## 判定
1つのメッセージで要約しきれないため、N 個に分割することを提案します。
理由: <混在している種類／責務など、分割が妥当な根拠を1〜2行で>

## 分割案
### コミット1: <種類>: <絵文字> 説明
- 対象: path/to/a, path/to/b

### コミット2: <種類>: <絵文字> 説明
- 対象: path/to/c

（必要に応じてコミット3, 4 ...）

この分割でよいですか？
- 「OK」で承認 → この順にステージし直してコミットします
- グループ分けやメッセージの修正があれば指示してください
- 分割せず1コミットにまとめたい場合はその旨を伝えてください
```

## 承認後の実行報告
コミット後は、実際に作成したコミット（ハッシュ短縮形とメッセージ）を簡潔に報告します。分割した場合は作成した各コミットを順に示します。
