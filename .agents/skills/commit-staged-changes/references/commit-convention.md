# コミットメッセージ規約

このリポジトリのコミットメッセージは、Conventional Commits 風の種類プレフィックスと Gitmoji を組み合わせます。

## 形式

```
<種類>: <絵文字> 説明
```

- 種類プレフィックスと絵文字プレフィックスを**必ず**組み合わせます。
- `説明` は変更内容を簡潔に表す日本語の subject です。敬体（です/ます）にはせず、名詞・体言止めで簡潔に書きます。
- subject は1行で、おおむね50文字以内を目安にします。1行で収まらないほど詰め込みたくなったら、分割を検討するサインです。
- 必要に応じて空行を挟み、本文（body）で「なぜ」を補足してかまいません。

例:

- `feat: ✨ Google Apps Script の初期設定`
- `feat: ✨ go-implementation-review を追加`
- `docs: 📝 system-design-assistant の記入例を修正`
- `fix: 🐛 ステージ判定の境界条件を修正`

## 種類と絵文字の対応表

| 種類 | 絵文字 | 用途 |
|------|--------|------|
| feat | ✨ | 新機能の追加 |
| fix | 🐛 | バグ修正 |
| docs | 📝 | ドキュメントのみの変更 |
| style | 💄 | コードの意味に影響しない変更 |
| refactor | ♻️ | 仕様変更を伴わないリファクタリング |
| perf | ⚡️ | パフォーマンス改善 |
| test | ✅ | テストの追加・修正 |
| chore | 🔧 | ビルドや補助ツールの変更 |
| merge | 🔀 | ブランチのマージ |
| remove | 🔥 | ファイルやコードの削除 |
| wip | 🚧 | 作業中のコミット（最終コミット前の一時保存に限定） |
| deps | ⬆️ | 依存関係の更新 |
| deps | ➕ | 依存関係の追加 |
| deps | ➖ | 依存関係の削除 |
| ci | 👷 | CI/CD の追加・更新 |

## 種類の選び方
- 1つの差分に複数の種類が当てはまる場合、それ自体が「単一のまとまりでない」サインです。分割を検討します（`split-guide.md` を参照）。
- どうしても1コミットにする場合は、その差分の**主目的**に当たる種類を選びます。整形やリネームが付随しているだけなら主目的側に寄せます。
